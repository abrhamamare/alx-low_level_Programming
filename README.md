# C Programming Foundations

Topic-organized C exercises covering pointers, memory allocation, recursion, linked lists, bit manipulation, file I/O, and hash tables.

## Technologies and topics

C, GCC, memory management, data structures.

## Getting started

Choose a numbered topic directory and compile the relevant source files following that exercise's requirements.

## Repository organization

Browse the source files and topic directories for individual examples. Some exercises are standalone and should not be compiled together.

## Technical interview discussion

Pointer ownership, bounds checking, dynamic allocation, and sanitizer-based debugging.

## Scope

Educational coursework and practice code. This repository is not claimed to be production-ready or security-audited.
